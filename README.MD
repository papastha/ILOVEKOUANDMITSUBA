## ILOVEKOUANDMITSUBA

# What It Is

A fan site about Kou and Mitsuba from TBHK with a rainbow corner with Naruto and Sasuke.

# Why I Made It

So I love scrolling on Tiktok and yk TBHK editors are amazing, and I saw a doomed edit of both of them so I decided I need to make something to encapsulate the doomedness with my own hands. Also, Naruto and Sasuke are there because come on, they are the founding fathers. My css skills were getting very dusty because of RENPY so decided to make something new.

# How I Made It
